🔑Gemini APIキーの取得

Gemini APIキーは、AIがレシートを読み取るために必要なキーです。Googleが提供する無料サービスで取得できます。

必要なもの：Googleアカウント（Gmailアドレス）のみ。費用は無料で取得できます。
※ 利用量が多い場合は有料になることがあります（月500枚程度で数百円の目安）。

手順

  1. Google AI Studio を開く
    aistudio.google.com
    上のアドレスをブラウザのアドレスバーに入力してアクセスしてください。
  2. Googleアカウントでログイン
    事務所で使用しているGmailアドレスでログインします。
  3. 「APIキーを取得」をクリック
    左側のメニューまたは画面上部に「Get API key」または「APIキーを取得」というボタンがあります。
  4. 「APIキーを作成」をクリック
    「新しいプロジェクトでAPIキーを作成」を選択してください。
    既存のプロジェクトがある場合はそちらを選択しても構いません。
  5. 表示されたAPIキーをコピーする
    「AIzaSy...」で始まる長い文字列がAPIキーです。コピーボタンをクリックしてコピーしてください。
    このキーは一度しか表示されない場合があります。必ずコピーしておいてください。
  6. スプレッドシートの設定シートに貼り付ける
    顧問先管理シート：設定シートの B2 セル
    顧問先シート：設定シートの B5 セル
    セルをクリックして選択し、Ctrl+V（Macは⌘+V）で貼り付けてください。
APIキーは他人に見せないでください
APIキーはパスワードと同じ扱いです。第三者に知られると、身に覚えのない料金が発生する恐れがあります。メール・チャット・スクリーンショットでの共有は避けてください。

クレジットカードの登録（無料枠を超えた場合）

無料枠を超えると「Resource has been exhausted」というエラーが表示されます。その際はGoogle Cloud コンソールでクレジットカードを登録してください。

  1. Google Cloud コンソールを開く
    console.cloud.google.com
  2. 左上のメニュー（≡）→「お支払い」をクリックします。
  3. 「お支払いアカウントを作成」→ 氏名・住所・クレジットカード番号を入力します。
  4. 登録後、再度レシートの読み取りをお試しください。
予算アラートの設定をおすすめします：
「お支払い」→「予算とアラート」から上限金額（例：月1,000円）を設定しておくと、万一の過大利用時にメールで通知が届きます。5分程度で設定できます。

🏛️国税庁 API ID の取得

国税庁が提供する無料のAPIを使い、レシートのT番号（インボイス登録番号）が有効かどうかを公式データベースと照合します。このIDを設定することで適格区分が「✅適格」または「❌非適格」と自動判定されます。

費用：無料　／　申請から発行まで：数日〜1週間程度
申請は事務所名義で行います。個人でも法人でも申請できます。

申請手順

  1. 国税庁 インボイス公表サイトを開く
    www.invoice-kohyo.nta.go.jp
    検索エンジンで「インボイス制度 適格請求書発行事業者 公表サイト」と検索してもアクセスできます。
  2. 「Web-API利用申請」を探してクリック
    ページ内の「Web-API機能のご案内」または「Web-API利用申請」のリンクをクリックしてください。
  3. 申請フォームに必要事項を入力
    以下の情報を入力します：
    ・申請者名（事務所名）
    ・メールアドレス（APIIDを受け取るアドレス）
    ・利用目的（例：「税理士業務における領収書のインボイス番号照合」）
  4. フォームを送信する
    送信後、確認メールが届きます。数日〜1週間以内にAPIIDがメールで届きます。
  5. 届いたAPIIDをスプレッドシートに貼り付ける
    顧問先管理シート：設定シートの B3 セル
    顧問先シート：設定シートの B6 セル
    IDは半角英数字の文字列です。コピー＆ペーストしてください。
APIIDが未設定の場合：
T番号の照合がスキップされ、適格区分はすべて「？不明」になります。会計ソフトには「80%控除」として出力され、仕訳メモに「インボイス要確認」と記録されます。後からIDを設定することもできます。
セキュリティについて：
このIDを設定することで、外部の中継サービスを一切介さず、事務所のGoogleアカウントから国税庁に直接通信してT番号を照合します。最も安全な方式です。
