1製品概要

Scan&Sheet AI は、Google スプレッドシートと Gemini AI を組み合わせた領収書・レシートの自動記帳ツールです。 スマートフォンやスキャナで撮影した画像をGoogleドライブに入れるだけで、AIが自動的に内容を読み取り、各会計ソフト向けの仕訳データに変換します。

主な機能

  • AIによるレシート・領収書の自動読み取り（日付・支払先・金額・税率・T番号）
  • 複数税率（10%・8%軽減）の自動分離記録
  • インボイス登録番号（T番号）の自動抽出と国税庁データベースとのリアルタイム照合
  • freee / マネーフォワード / 弥生 / TKC FX4クラウド / JDL IBEX / ミロク への出力対応
  • 顧問先ごとに独立したスプレッドシートで完全分離管理
  • 電子帳簿保存法対応（原本リンク・登録日時の自動記録）
  • 重複データの自動検出（日付＋支払先＋金額で判定）
  • 大量処理対応（時間制限を超えた場合は自動で続きから再開）

このマニュアルの読み方

本マニュアルでは、作業の場所を以下のバッジで区別しています。

バッジ意味
スタッフ事務所スタッフが日常的に行う操作です
顧問先管理シート管理用スプレッドシートで行う操作です
顧問先シート顧問先別スプレッドシートで行う操作です

2システム構成

Scan&Sheet AI は 2種類のスプレッドシート を使って管理します。

管理用スプレッドシート（顧問先管理シート）顧問先管理シート

事務所全体を一括管理するスプレッドシートです。初回セットアップ後は、顧問先を追加するときだけ操作します。

  • 顧問先の一覧管理
  • 顧問先別フォルダ・スプレッドシートの自動生成
  • Gemini APIキー・国税庁API IDの管理

設定シートのセル構成：

セル項目内容
B1種別「ADMIN」固定（自動設定）
B2Gemini APIキーAIの読み取りに使用するAPIキー
B3国税庁 API IDインボイスT番号照合用のID（無料）

顧問先別スプレッドシート（顧問先シート）顧問先シート

顧問先ごとに自動生成されるスプレッドシートです。日常業務はここで行います。

  • 作業シート：AI処理・重複チェック・確定の3ステップ操作パネル
  • 全体シート：確定済みの全レシートデータを蓄積
  • 転記シート：確定のたびに自動作成（例：「2026.6.22 freee」）
  • 科目コードマスタ：TKC / JDL / ミロク 使用時のみ表示

設定シートのセル構成：

セル項目内容
B1種別「CLIENT」固定（自動設定）
B2顧問先名顧問先の名前（自動設定）
B3未処理フォルダID自動設定（変更不可）
B4処理済みフォルダID自動設定（変更不可）
B5Gemini APIキーセットアップ時に設定
B6国税庁 API IDセットアップ時に設定
B7TKC 関与先コードTKC使用時のみ（3〜4桁の数字）
⚠️ 顧問先シートは顧問先と共有しないでください：
顧問先シートの設定シートにはGemini APIキーが記載されています。顧問先にスプレッドシートを共有すると、APIキーが漏洩し、第三者に悪用される恐れがあります。顧問先に操作させる必要がある場合は、レシートを「未処理」フォルダに入れるだけにとどめ、シート自体は共有しないでください。

3初回セットアップ

初回セットアップはご自身のGoogleアカウントで行っていただきます。手順に不安がある場合は 丸投げプラン にてオンラインで伴走サポートを提供しています。お気軽にご相談ください。

3-1. 顧問先管理シートの初回セットアップ 顧問先管理シート

  1. 顧問先管理シートを開きます。上部メニューに「経費記帳（管理）」→「初回セットアップ」が表示されます。
  2. 【ステップ 1 / 3：ライセンス確認】
    現在ログイン中のGoogleアカウントが表示されます。「OK」をクリックするとライセンスを確認します。
  3. 【ステップ 2 / 3：シートの作成】
    「設定」シートと「クライアント管理」シートが自動で作成されます。
  4. 【ステップ 3 / 3：APIキーの設定】
    「設定」シートの B2 セルに Gemini APIキー、B3 セルに国税庁 API ID を貼り付けます。
    取得方法がわからない場合は → APIキー・国税庁ID 取得ガイド

3-2. 顧問先の登録（フォルダ・スプレッドシートの自動生成）顧問先管理シート

顧問先管理シートの「クライアント管理」シートで顧問先を登録すると、フォルダと顧問先シートが自動的に作成されます。

  1. 「クライアント管理」シートを開きます。
  2. A列（7行目以降）に顧問先の名前を入力します。（例：「山田工務店」「鈴木農業」）
  3. C列（使用会計ソフト）をドロップダウンから選択します。freee / MF / 弥生 / TKC / JDL / ミロク（省略するとfreeeになります）
  4. E列（顧問先Gmail）に顧問先のGmailアドレスを入力すると、自動で共有設定が行われます。
  5. A4 のチェックボックスをオンにします。入力した顧問先のフォルダと顧問先シートが自動で生成されます。
自動で作成されるもの：
① 「Scan&SheetAI」フォルダ内に「顧問先名」フォルダ
② その中に顧問先シート「顧問先名_SS」、「未処理」フォルダ、「処理済み」フォルダ
③ E列にGmailがあれば、そのアドレスへの共有設定（編集者権限）
顧問先名は後から変更しないでください。
顧問先名はフォルダ名・シートのタイトルに使用されます。登録後に変更するとフォルダ名との不一致が生じます。

3-3. 顧問先シートの初期設定 顧問先シート

新しく作られた顧問先シートを初めて開いたら、チェックボックスを動作させるための初期設定を行います。これを行わないとチェックボックスでの操作ができません。

  1. 作成された顧問先シートを開きます。
  2. 上部メニューの「経費記帳」→「初期設定（最初の1回のみ）」をクリックします。
  3. ライセンスの確認が行われます。問題なければ「✅ 初期設定が完了しました」のダイアログが表示されます。
  4. 設定シートの B5 に Gemini APIキー、B6 に国税庁 API IDを貼り付けます。
    取得方法がわからない場合は → APIキー・国税庁ID 取得ガイド
初期設定はライセンス購入者のアカウントでのみ実行できます：
初期設定の実行時にライセンス認証が行われます。購入時に登録したGoogleアカウント以外では認証が通らないため、顧問先が誤って実行しようとしてもエラーになります。事務所のスタッフが事務所のアカウントでログインした状態で実行してください。

3-4. TKC / JDL / ミロク の追加設定 顧問先シート

TKC・JDL・ミロクをご利用の場合、科目コードの設定が必要です。freee・MF・弥生はこの設定は不要です。

  1. メニューの「経費記帳」→「科目コードマスタを初期化（JDL / TKC / ミロク）」をクリックします。
  2. 「科目コードマスタ」シートが開き、サンプルデータが挿入されます。
  3. B列（科目コード）を、ご利用の会計ソフトの実際の科目コードに書き換えてください。
    A列「勘定科目名」はAIが出力する名称と完全一致させることが重要です。
  4. 特に「現金」の科目コード（貸方科目として使用）を必ず設定してください。
TKC をご利用の場合の追加設定：
設定シートの B7 セルに、TKCの関与先コード（3〜4桁の数字）を入力してください。このコードは顧問先ごとに異なります。TKCの管理画面からご確認ください。

4日常業務の流れ

セットアップ完了後の日常業務は、顧問先シートの「作業シート」で3ステップで完結します。

準 領収書をスキャン・撮影して「未処理」フォルダに入れる
↓
① AI処理開始のチェックボックスをオン → 自動読み取り
↓
② 日付順並べ替え＋重複チェックのチェックボックスをオン → 内容を確認・修正
↓
③ 確定して転記のチェックボックスをオン → 全体シートへ蓄積・転記シート自動作成
↓
出 転記シートをCSVでダウンロードして会計ソフトにインポート

準備：領収書をスキャン・撮影して「未処理」フォルダに入れる スタッフ

スキャナやスマートフォンで領収書・レシートを撮影し、該当顧問先の 「未処理」フォルダ に保存してください。

対応ファイル形式：JPEG・PNG・GIF・WebP・HEIC（iPhone撮影）・PDF
ScanSnap Cloud を使うと便利です：
ScanSnap iX シリーズは、ScanSnap Cloud 経由でPCなしに直接Google Driveへ送信できます。顧問先フォルダの「未処理」フォルダをスキャン先に設定しておくと、スキャンボタン1つで自動的に投入されます。
Google ドライブ for Desktop を使うと便利です：
Google Drive for Desktop をインストールするとGoogleドライブがWindowsエクスプローラー上のフォルダとして表示されます。ファイルをドラッグ＆ドロップするだけで「未処理」フォルダに投入できます。

① AI処理開始 スタッフ クライアントSS

「作業シート」の上部にある3行のボタンパネルを使います。

  1. 顧問先シートの「作業シート」タブを開きます。
  2. 作業シート上部の「① AI処理開始」行のチェックボックスをオンにします。
  3. 処理が始まります。右のステータス欄に「処理中... (○件)」と表示されます。
  4. 完了すると「○件完了（時刻）」と緑色で表示されます。
処理時間の目安：1枚あたり5〜15秒かかります。チェックボックスをオンにしたらそのままお待ちください。シートを閉じても処理は継続します。

大量処理（約30枚以上）の場合：Google Apps Script の実行時間制限（4分30秒）を超えた場合、「残り○件 → 約1.5分後に自動で続行します」と表示されます。そのまましばらく待つと自動的に続きから処理が再開されます。チェックボックスを再度オンにする必要はありません。
作業シートに前回のデータが残っている場合：
確定されていないデータが残っている場合、上書きするか確認ダイアログが表示されます。前回データを先に確定する場合は「いいえ」を選び、③の「確定して転記」を先に実行してください。

② 日付順並べ替え＋重複チェック スタッフ

AIが読み取った内容を確認・修正します。

  1. 作業シート上部の「② 日付順に並べ替え ＋ 重複チェック」行のチェックボックスをオンにします。
  2. データが日付順（古い順）に並べ替えられます。
  3. 日付・支払先・金額が同じデータは重複の可能性があるため黄色でハイライトされます。内容を確認して不要な行は削除してください。
  4. 8行目以降のデータを直接確認・修正してください。

修正が必要な主な項目：

  • 勘定科目：AIが自動判定しますが、必要に応じて手修正してください。修正を繰り返すことで読み取り精度が上がります。
  • 適格区分：T番号を国税庁データベースと照合し「✅適格」「❌非適格」「？不明」を自動判定します。必要に応じてドロップダウンで変更できます。
  • 税率：10% / 8% / 0% のドロップダウンで変更できます。
  • 内容・摘要・補助科目・部門：自由に修正・追記できます。
  • メモ列：AIの読み取り精度が低いと判断したセルが黄色になります。メモ欄に理由が記載されているので確認してください。
原本リンク（M列）：Googleドライブの画像ファイルに直接リンクするハイパーリンクが自動設定されます。電子帳簿保存法の要件（原本の参照可能性）を満たします。

③ 確定して転記 スタッフ

  1. 作業シート上部の「③ 確定して転記」行のチェックボックスをオンにします。
  2. 以下の処理が自動で実行されます：
    ・作業シートのデータが「全体」シートに追記（蓄積）される
    ・転記シートが自動作成される（例：「2026.6.22 freee」）
    ・処理済みの画像ファイルが「処理済み」フォルダへ自動移動される
    ・作業シートがクリアされ、次回の処理に備える
  3. 「✅ 完了：転記○件 / PDF移動○件（時刻）」と表示されたら完了です。
AI処理が途中で中断した状態で確定しようとした場合：
「まだ○件のファイルが処理待ちです」という確認が表示されます。残りのファイルも処理する場合は「いいえ」を選び、①チェックボックスを再度オンにして続きを処理してください。

5会計ソフトへの出力

確定操作を行うと、その都度 転記シート が自動作成されます。シート名は「2026.6.22 freee」のように日付と会計ソフト名が付きます。

転記シートのCSVダウンロード手順

  1. スプレッドシート下部のタブで転記シート（例：「2026.6.22 freee」）をクリックして開きます。
  2. メニューの「ファイル」→「ダウンロード」→「カンマ区切り形式（.csv）」を選択します。
  3. ダウンロードしたCSVを各会計ソフトにインポートします。
転記シートは毎回新しく作成されます：
確定するたびに「2026.6.22 freee」「2026.6.22 freee(2)」のように日付付きで新しいシートが追加されます。古い転記シートを削除しても全体シートのデータには影響しません。

会計ソフトインポート場所注意事項

過去データの再出力（全体シートから期間指定）

「全体」シートには確定済みのすべてのデータが蓄積されています。過去の特定期間のデータを会計ソフトに入れ直したい場合は、全体シートのデータを直接フィルタリングしてCSV出力することができます。

  1. 「全体」シートを開きます。
  2. Googleスプレッドシートのフィルタ機能（ビュー > フィルタを作成）を使い、A列（日付）で期間を絞り込みます。
  3. 「ファイル」→「ダウンロード」→「カンマ区切り形式（.csv）」でダウンロードします。

7よくある質問

「経費記帳」メニューが表示されません

スプレッドシートを再読み込み（F5キーまたはブラウザの更新ボタン）してください。顧問先シートを初めて開いた場合は「初期設定（最初の1回のみ）」を実行する必要があります。

チェックボックスをオンにしても何も起きません

「初期設定（最初の1回のみ）」が完了していない可能性があります。メニュー「経費記帳 > 初期設定（最初の1回のみ）」を実行してください。なお、チェックボックスを操作するアカウントは初期設定を実行したアカウントと同じでなければなりません。

「ライセンスエラー」が表示されます

購入時に登録したGoogleアカウントと異なるアカウントでログインしている可能性があります。正しいアカウントでログインしてから再度「初期設定」を実行してください。それでも解決しない場合は OFFICE REIS にお問い合わせください。

AIの読み取り結果が間違っています

②の重複チェックステップで作業シートのデータを直接修正してください。確定（③）前であればいつでも修正できます。画質が低い場合は、より鮮明な画像で再スキャンして再度①から処理してください。

処理が「残り○件 → 約1.5分後に自動で続行します」で止まっています

そのままお待ちください。約1〜2分後に自動的に続きから処理が再開されます。ブラウザを閉じても構いません。しばらくしてからスプレッドシートを開き直すと、処理が完了しているはずです。完了していない場合は①チェックボックスをもう一度オンにしてください。

1枚のレシートに10%と8%の商品が混在しています

AIが自動的に税率ごとに2行に分けて記録します。それぞれの税率の小計が記録されるため、会計ソフトへのインポートもそのまま行えます。

適格区分が「？不明」になります

主な原因は2つです。①国税庁 API IDが設定シートB6に設定されていない。②レシートにT番号が印字されていない（T番号なしの領収書は適格請求書ではないため「❌非適格」に手修正してください）。国税庁 API IDの取得・設定については OFFICE REIS にご相談ください。

新しい顧問先を追加するにはどうすればいいですか

顧問先管理シートの「クライアント管理」シートに顧問先名を追加してA4のチェックボックスを押すと、フォルダと顧問先シートが自動生成されます。

Gemini APIの利用料金はかかりますか？

少量であれば無料枠で賄えますが、会計事務所での日常的な利用では超える可能性が高いだけでなく、途中で止まるなど、作業効率が下がります。ストレスなく作業するため、クレジットカードを登録した有料プランをご利用ください。月500枚程度の処理で400円程度（Gemini 2.5 Flashの場合）の目安です。利用した分だけの従量課金でＡＩ使用料の月額固定費はかかりません。

APIキーの取り扱いにご注意ください：
APIキーは他人に知られないようにしてください。第三者に悪用されると身に覚えのない高額請求が発生する恐れがあります。設定シートのセル値をスクリーンショットで共有することは避けてください。
「Gemini APIエラー: Resource has been exhausted」と表示されました

Gemini APIの無料枠を超えています。Google Cloud コンソール（console.cloud.google.com）でクレジットカードを登録して有料プランに移行してください。

  2. 左上のメニュー →「お支払い」をクリック

  4. 登録後、再度レシートの読み取りをお試しください
支出上限・予算アラートの設定をおすすめします：
AI Studio の設定から月額支出上限（金額）を設定でき、上限到達で API が自動停止します。予算アラートと組み合わせることで過大利用を確実に防げます。
