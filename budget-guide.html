💴① 月額支出上限の設定（金額で制限）

AI Studio の設定から、プロジェクトごとに月の支出上限を金額で設定できます。上限に達すると API が自動的に停止します。最初にこの設定を行うことをおすすめします。

予算アラートとの違い：予算アラートはメール通知のみですが、月額支出上限は上限到達で API が実際に停止します。過大利用を確実に防ぎたい場合はこちらの設定をおすすめします。

設定手順

  1. AI Studio の支出管理ページを開く
    aistudio.google.com/spend
    APIキー取得時に使用したGoogleアカウントでログインしてください。
  2. 「Monthly spend cap」の「Edit spend cap」をクリック
  3. 上限金額を入力して保存
    月500枚程度の処理で400円（約3ドル）程度が目安です。余裕を持って1,000〜2,000円程度に設定することをおすすめします。
    ※ 金額はドル（USD）で入力します。1ドル＝約150円で換算してください。
注意：上限超過のタイミングにずれが生じる場合があります
バッチ処理など大量のリクエストが集中した場合、約10分程度の請求遅延により上限をわずかに超過することがあります。安全のため、実際の使用見込み額より少し高めに設定してください。

🔔② 予算アラートの設定（通知）

Google Cloud の予算アラートを設定すると、Gemini API の利用料金が設定した金額に達した際にメールで通知が届きます。月額支出上限と組み合わせることで二重の安全策になります。

設定時間の目安：約5分　／　費用：無料
アラートはあくまで通知です。設定金額を超えても自動的にAPIが停止するわけではありません。

手順

  1. Google Cloud コンソールを開く
    console.cloud.google.com
    APIキー取得時に使用したGoogleアカウントでログインしてください。
  2. 左上のメニュー（≡）→「お支払い」をクリック
    メニューが見つからない場合は画面左上の三本線アイコンをクリックしてください。
  3. 左側のメニューから「予算とアラート」をクリック
  4. 「予算を作成」をクリック
  5. 予算の名前と金額を入力する
    名前：例「Gemini API 月次予算」
    予算の種類：「指定金額」を選択
    金額：例「1000」（円）
    月500枚程度の処理では400円程度が目安です。余裕を持って1,000円程度に設定しておくことをおすすめします。
  6. アラートのしきい値を設定する
    「しきい値のルールを追加」で通知タイミングを設定します。
    例：50%（500円）・90%（900円）・100%（1,000円）の3段階が目安です。
  7. 通知先メールアドレスを確認して「完了」をクリック
    デフォルトでは請求アカウントの管理者メールアドレスに通知が届きます。変更が必要な場合は「メール受信者を管理」から設定してください。
設定完了後の動作：
設定したしきい値（例：50%・90%・100%）に達するたびにメールが届きます。100%を超えても API は停止しませんが、通知をもとに利用状況を確認してください。

🚦③ 利用上限（クォータ）の設定（枚数で制限）

予算アラートは通知のみで自動停止はしません。1日あたりのリクエスト数に上限を設定することで、使いすぎを物理的に防ぐことができます。

クォータとは：APIへのリクエスト回数の上限設定です。上限に達すると処理がエラーになり、それ以上の課金が発生しなくなります。翌日0時（UTC）にリセットされます。

設定手順

  1. Google Cloud コンソールを開く
    console.cloud.google.com
  2. 左上のメニュー（≡）→「APIとサービス」→「有効なAPIとサービス」をクリック
  3. 一覧から「Gemini API」をクリック
    見つからない場合は検索ボックスで「Gemini」と入力してください。
  4. 上部タブの「割り当てと上限」をクリック
  5. 制限したい項目の右端の鉛筆アイコン（編集）をクリック
    例：「Requests per day per project」（1日あたりのリクエスト数）を選択します。
    月500枚の処理で1日あたり約25〜50リクエスト程度が目安です。余裕を持って500〜1,000程度に設定しておくことをおすすめします。
  6. 上限値を入力して「保存」をクリック
    設定が反映されるまで数分かかる場合があります。
予算アラートとの組み合わせがおすすめ：
クォータで物理的な上限を設け、予算アラートで金額の監視をする2段構えの設定が安心です。
上限に達した場合の動作：
処理中にクォータ上限に達すると「Resource has been exhausted」エラーが表示されます。翌日に自動でリセットされるまで AI 読み取りができなくなりますのでご注意ください。上限値は余裕を持って設定してください。
